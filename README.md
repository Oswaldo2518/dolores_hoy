
# Dolores Hoy
## Flutter + 5 APIs gratuitas con seguridad

Aplicación desarrollada en Flutter utilizando TDD y MockClient para consumir cinco APIs: Open-Meteo, Frankfurter, Nager.Date, Wikipedia y NASA.
